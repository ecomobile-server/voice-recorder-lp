# Voice Recorder Landing Page

A dark neon landing page for **Voice Recorder & AI Transcribe**, inspired by the supplied Soundscape Studio reference.

## Run

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Notes

- No framework or build step required.
- Responsive desktop/mobile layout.
- Small vanilla-JS interactions: reveal-on-scroll, live recorder timer, pause/resume, hover/parallax.
- Product screenshots, feature graphic and app icon are stored locally in `assets/`.
